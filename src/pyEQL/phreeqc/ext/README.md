## External Dependencies

### IPhreeqc

The contents of the `iphreeqc-*` folder are extracted from the IPhreeqc module ("Linux (the `tar.gz` file)")
downloaded from `https://github.com/phreeqc-dev/iphreeqc/releases`.

Specifically, at the time of this writing (10/31/2025), the file
`https://github.com/phreeqc-dev/iphreeqc/releases/download/v3.8.6/iphreeqc-3.8.6-17100.tar.gz`
(md5sum: `91d8485139b423d5f0382e9215d9aea1`)

These releases are made ~6 months. **Official** USGS releases are less frequent, and can be downloaded from:
`https://water.usgs.gov/water-resources/software/PHREEQC`

If downloading from USGS, look for the `Linux (any processor)` version of the `.tar.gz` file.
