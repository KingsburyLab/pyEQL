### IPhreeqc

The contents of the `iphreeqc-*` folder are extracted from the IPhreeqc module (the `tar.gz` file)
downloaded from `https://github.com/phreeqc-dev/iphreeqc/releases`.

Specifically, at the time of this writing (10/23/2026), the file
`https://github.com/phreeqc-dev/iphreeqc/releases/download/v3.9.0/iphreeqc-3.9.0-17591.tar.gz`
(md5sum: `488ecdfbe794a1c16d18602906e34a40`)
